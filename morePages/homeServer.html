TrueNAS Scale Home Server

This page is the expanded overview of my home server build. It runs 24/7 as my personal platform for media, backup storage, and self hosted tools.

Current Hardware: Cisco UCS C240 M3S, 24 bay storage array, 756GB of ECC3 ram and a 2 Xeon E5-2680 v2 CPUs.

Core Services

  • Jellyfin for perosnal media streaming
  • Immich for photo backup and organization
  • WireGuard for secure remote access
  • SMB shares for local file storage
  • Proxmox VMs/containers for experiments

Why I Have It

I wanted full control over my data and services while learning enterprise hardware and real world system administration.

This project gives me hands on experience with virtualization, Linux management, backups, and networking.

Planned Upgrades

  • Add automated off site backup replication
  • Improve service monitoring and alerting
  • Document full network + storage diagrams
  • Deploy reverse proxy + TLS for external apps

Stack: TrueNAS Scale, Docker, Linux, SMB, WireGuard, Proxmox

Status

This is a starter page and will keep growing as I expand the server, add new services, and tune performance.
