TrueNAS Scale Home Server

hardware self-hosted linux enterprise docker 24/7 uptime

Self hosted services, through my Cisco UCS C240 M3 Enterprise server. I am a hardware enthusiast by heart and love everything data hoarding. It runs 24/7 as my personal platform for media, backup storage, and self hosted tools.

Hardware: Cisco UCS C240 M3S, 24 bay storage array, 756GB of ECC3 RAM, dual Xeon E5-2680 v2 CPUs.

Core Services

  • Jellyfin — personal media streaming
  • Immich — photo backup and organization
  • WireGuard — secure remote access
  • SMB — local file storage
  • Proxmox — VMs and containers for experiments

I wanted full control over my data and services while learning enterprise hardware and real world system administration. This project gives me hands on experience with virtualization, Linux management, backups, and networking.

Planned Upgrades

  • Add automated off-site backup replication
  • Improve service monitoring and alerting
  • Document full network + storage diagrams
  • Deploy reverse proxy + TLS for external apps
