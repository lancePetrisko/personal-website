# Personal Portfolio Website

A static personal portfolio site built with plain HTML, CSS, and vanilla JavaScript. No frameworks, no build tools, no dependencies.

## Tech Stack

HTML5 / CSS / Vanilla JS / [Roboto Mono](https://fonts.google.com/specimen/Roboto+Mono) / GitHub Pages

## Running Locally

No build step required. Serve the root directory with any static file server:

```bash
python3 -m http.server 8000
```

Or just open `index.html` directly in a browser.
